**Summary.** Fourth-order Åström–Bell drum model behind `drum.model: astrom_bell`

**Method note.** The model equations were transcribed from the paper itself (fetched
the Automatica PDF, read pp. 1–12) — not from memory. Eq. 24 e-coefficients, void
relations (12/26), circulation (15), level (19–20), §4.8 equilibria. Parameter

paper plant's ~300).

**Two real findings (both in HANDOFF):**
- D18: with the AB drum and our cold feed, single-element level control is unstable —
  feed cut → less drum condensation → V_sd grows (−0.166 m³ per kg/s) → level rises
  further; load_step ran away to DRUM_LVL_HIHI/turbine trip. Diagnosed via state-table
  probe (V_sd 4.65→13.9 m³ as feed → 0). Fix: the M4 pairing is AB + three-element
  with a deliberately SLOW trim (15/0.15/±25); aggressive trim (60/1.5/±45)
  demonstrated unstable (peak 719 mm). Tuning sweep evidence in session probes.
- D19: the path-flow solver's loose warm-start-dependent exit made the steady-state
  root's FD Jacobian see iteration noise (near-null fw_valve.x column, SVD-diagnosed);
  hybr stalled at off-design loads with the AB drum. Fixed by converging on
  |Δq| < 1e-13·q_hi. Also required nondimensionalizing the root unknowns by state
  spans.

**Key decisions.**
- *Manual trips reuse the protective code path rather than duplicating it.*
  Extracted `_do_mft` / `_do_turbine_trip` from `_apply_protective_actions` as a
  behavior-neutral refactor FIRST, confirmed the 37-test 0.1.0 suite still passed,
  and only then added the actions. Makes "semantics identical to the corresponding
  protective action" (§11.1) structural instead of a claim. Rejected: writing the
  manual path separately — it would drift.
- *Accessors named `*_path()` and return `importlib.resources` traversables.*
  The plan's §11.3 names (`baseline_config()`) were illustrative ("e.g."); the
  `_path` suffix makes the return type honest, and traversables keep working from a
  zipped install. `read_text()` consumes a traversable or a user path uniformly.
  Rejected: returning parsed objects — the loaders already do that, and paths are
  the composable primitive the panel's scenario picker needs.
- *Manual trips carry no engine latch,* so `trips.reset` clears them. Follows the
  existing D14 convention for scenario-injected pump trips rather than inventing a
  second latch class.
- *Re-pressing an already-latched trip is rejected-and-recorded* with a reason
  ("MFT already latched") rather than silently ignored — the panel prints rejection
  reasons verbatim in its SOE log, so this is operator feedback.
- *`label` validation is 1–2 lines × ≤ 12 chars,* enforced at load. Default falls
  back to the bare id (`Condition.legend`), which may exceed 12 chars — ids like
  `DRUM_LVL_LOLO` are 13 — but all 19 shipped entries now carry an explicit legend,
  so the fallback is a robustness path only.

**Bug/trap found and avoided.** A chdir-to-tmpdir test for §11.3 would have been
decorative: under an editable install `Path(__file__).parents[3]` still resolves
into the repo checkout, so such a test passes against the *pre-migration* code and
