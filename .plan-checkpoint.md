## Constraints

- Fixed-step RK4, dt = 0.05 s; no adaptive/implicit solvers (§1, locked).
- Discrete state frozen during RK4 stage evaluations; updated only at step boundaries by event layer (§1, §3.2).
- No fast pressure nodes as ODE states — quasi-static algebraic flow network inside derivative (§1, §5.6).
- Determinism: seed + scenario + platform ⇒ bit-identical; all randomness from one numpy.random.Generator owned by simulator (§1).
- SI units internally everywhere; docstrings/constants state units (§1).
- Controllers and protection act on **sensed** values, not truth (§1, §8).
- Runtime deps: numpy, scipy, pyyaml ONLY. Dev: pytest, ruff, matplotlib (scripts only, never imported by package) (§1).
- No frameworks: no component graph, units lib, pydantic, plugins, async, numba (§1).
- Python ≥ 3.11, src/ layout, stdlib dataclasses (§1).
- Component files ≲ 300 lines; ruff clean; type hints on public APIs (§13).
- Step sequence strict order per §3.2 (actions → controllers → RK4 → events → sensors → historian).
- Protection table is data-driven YAML (§7); scenario YAML per §9; observation/action contracts per §8.
- Auto-standby default OFF in all canonical scenarios (§9).
- Milestone gating: tests green + HANDOFF.md update + small focused commits per milestone; never start next milestone red (§12).
- M4 (AstromBellDrum, three-element FW) ONLY on explicit go-ahead — T9 committed as skipped test (§11 T9, §12).
- Ask-vs-decide: simplest deterministic choice, recorded in HANDOFF.md "Decisions taken"; stop only if a locked decision is unworkable (§13).
- No silent physics fudging; document timing-target misses rather than inventing constants (§13).
- Out of scope (§14): web/UI/agent/gym wrapper, superheater/reheat/extraction heaters, makeup/blowdown, multi-machine grid, display units, sound/scoring, perf beyond T11.
- CoolProp must NOT be a runtime dependency; property fits committed with provenance + accuracy report (§5.1).
