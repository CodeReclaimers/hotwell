## Plan approval (commit f13c60e)

The plan was drafted after a benchmark-design discussion. The first evaluation target is
"Idea 2": a 24-h plant data dump with one injected fault; the model names the fault and its
onset. Alan's decisions:

- Fix gap 4 (backpressure-independent turbine work, no low-vacuum trip) **always on**,
  not config-gated. Rejected: config-gating (two physics to maintain), and disclose-only
  (air-ingress items would lose their operating consequence).
- Background ops come from a **closed-loop procedure runner**. Rejected: open-loop
  event expansion, because an op that meets a fault plays out blindly (it would stop
  CP-1 after CP-2 failed to start), so that cascade would be caused by a bad operator,
  not the injected fault.
- Repo split: mechanisms, procedures and manuals in hotwell; the generator and grader
  in a new hotwell-bench repo.
- Manual units: SI with customary in parentheses.
- Q1 keep the inlet-pressure dependence of w; Q2 COND_P_HIHI 18 kPa / 5 s, range
  unchanged; Q3 tag v0.3.0 and pin the panel before M2; Q4 fault list approved;
  Q5 add a simple makeup system (new M5b; a tube leak otherwise drains the closed
  cycle within hours).

## M0 — golden hashes + observation hash

### Changes
- `src/hotwell/sensors.py`: new public `observation_bytes(obs)`. Sensed values as
  float64 in `OBSERVATION_SPEC` order, then indications in sorted-key order as
  `key=value\0` (bool → `1`/`0`). Alarms and `plant_dead` are excluded, following the plan
  text ("values, then indications").
- `src/hotwell/simulator.py`: `_obs_hash` updated in `step()` right after the state-hash
  update; `observation_hash` property. Post-step only, the same rule as the state hash.
- `tests/test_golden_hashes.py` (new): 6 parametrized golden runs + determinism +
  empty-digest-before-first-step.
- `scripts/golden_hashes.py` (new): independent generator. It computes the
  observation hash **outside** the simulator from the returned `Observation`s, so the
  in-simulator implementation is checked against code it doesn't share.

### Verification
- `.venv/bin/python -m pytest tests/test_golden_hashes.py -s -q` → `8 passed in 22.52s`
  (each case prints the computed vs. golden hash pair).
- Full suite: `.venv/bin/python -m pytest -q` → `69 passed in 62.92s` (61 before + 8 new).
- `.venv/bin/python -m ruff check .` → `All checks passed!`
- **Gate can fail** (mutation check, ad-hoc, not committed):
  `kp*(1+1e-7): state differs: True  obs differs: False`;
  `reversed indications: state same: True  obs differs: True`.
  Finding: the observation hash does **not** see a 1e-7 relative gain change, because
  quantization absorbs sub-LSB differences in truth. The state hash is the
  physics-neutrality gate; the observation hash guards the exported data. Documented
  in the test docstring and the HANDOFF.
